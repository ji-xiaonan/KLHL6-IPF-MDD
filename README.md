# KLHL6-IPF-MDD

## Overview

This repository contains R scripts associated with the study entitled "Integrated bioinformatics analysis and experimental validation identify KLHL6 as a candidate molecule associated with idiopathic pulmonary fibrosis and major depressive disorder."

The study investigates disease-associated molecular alterations in idiopathic pulmonary fibrosis (IPF) and major depressive disorder (MDD) through comparative bioinformatics analyses and experimental validation.

## Analysis Methods

The study includes the following computational approaches:

- Differential gene expression analysis
- Weighted gene co-expression network analysis (WGCNA)
- Functional enrichment analysis
- Machine learning-based candidate gene identification
- Immune infiltration analysis
- Single-cell transcriptomic analysis
- Cell-cell communication analysis
- Statistical analysis and visualization

## Programming Language

R

## Data Sources

Publicly available transcriptomic datasets were obtained from the Gene Expression Omnibus (GEO) database:

- GSE53845
- GSE39653
- GSE136831
- GSE213982
